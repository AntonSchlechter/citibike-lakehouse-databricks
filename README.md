# 🚴‍♂️ Citi Bike Lakehouse on Databricks

End-to-End Data Engineering & Machine Learning Project using Databricks Lakehouse Architecture.

---

## 📌 Project Overview

This project demonstrates how to build a modern data platform using Databricks.
Using Citi Bike trip data, we implement a full **Lakehouse architecture** including:

* Data ingestion (batch & streaming)
* Data transformation (Bronze → Silver → Gold)
* Data quality checks
* SQL analytics & dashboards
* Machine Learning with MLflow
* Workflow orchestration
* Data governance with Unity Catalog
